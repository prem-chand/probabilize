While this produced models that generalized reasonably well, supervised pretraining suffers from fundamental limitations when scaling toward foundation models: 1. Annotation Bottleneck: Curating high-quality, dense annotations scales linearly in human effort. Web-scale image data (e.g., billions of images) is abundant, but labeling it is economically prohibitive. 2. Semantic Bottleneck: Supervised objectives force the network to compress its representation into a fixed, mutually exclusive set of classes (a one-hot vector). A model trained to classify "dog" vs. "cat" learns to aggressively discard background information, fine-grained object attributes, and relative spatial positioning, as these are "distractors" to the classification objective. Self-supervised learning bypasses both bottlenecks by converting unlabeled abundance into a continuous, high-dimensional training signal. By constructing proxy tasks (pretext tasks) that require the model to understand image structure to solve them, the model learns general-purpose visual representations that transfer broadly to downstream tasks. # --- Contrastive toy: 3 classes, two augmented views each ---
def normalize(v):
    return v / (np.linalg.norm(v, axis=-1, keepdims=True) + 1e-8)

# True class prototypes
proto = normalize(np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]], dtype=float))
# Start with noisy embeddings for two views of each class
z1 = normalize(proto + 0.4 * np.random.randn(3, 3))
z2 = normalize(proto + 0.4 * np.random.randn(3, 3))

def info_nce_step(z_a, z_b, lr=0.5, tau=0.2):
    """One gradient step: attract matched pairs, repel others (symmetric sketch)."""
    sim = (z_a @ z_b.T) / tau  # [i,j] = sim(view1_i, view2_j)
    # For each i, positive is j=i
    for i in range(len(z_a)):
        logits = sim[i]
        p = np.exp(logits - logits.max())
        p = p / p.sum()
        # gradient on z_a[i]: pull toward z_b[i], push from others
        grad = (p[i] - 1.0) * z_b[i]  # simplified
        for j in range(len(z_b)):
            if j != i:
                grad = grad + p[j] * z_b[j]
        z_a[i] = normalize(z_a[i] - lr * grad)
    return z_a

print("Contrastive alignment (cosine of matched pairs):")
print(f"  before: {np.round(np.sum(z1 * z2, axis=1), 3)}")
for _ in range(40):
    z1 = info_nce_step(z1, z2)
    z2 = info_nce_step(z2, z1)
print(f"  after:  {np.round(np.sum(z1 * z2, axis=1), 3)}")
print(f"  off-diag mean sim: {np.mean(z1 @ z2.T - np.diag(np.diag(z1 @ z2.T))):.3f}")
print("Notice: positives align; unrelated classes stay farther — global semantics, not dense layout.\n")
