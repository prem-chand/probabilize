Week 13: Nonconvex Deep Learning

Learning Outcomes
  • Classify a critical point as a minimum, saddle or maximum from its Hessian
  • Compute how many extra steps gradient descent spends near a saddle, and explain why a plateau is not a minimum
  • State what overparameterization does to local minima, and which part is proven
  • State how initialization (He, Xavier) and normalization shape the loss surface, and which convex tools still transfer

Why the path stalls near a saddle#

The coordinates descend independently, and the Hessian is diagonal, ∇2f=diag(12u2−4,  6v2−2)\nabla^2 f = \mathrm{diag}(12u^2 - 4,\; 6v^2 - 2)∇2f=diag(12u2−4,6v2−2). A point with ∇f=0\nabla f = 0∇f=0 is a minimum when every eigenvalue is positive, a maximum when every one is negative, and a saddle when the signs are mixed. The origin, with diag(−4,−2)\mathrm{diag}(-4, -2)diag(−4,−2), is a maximum. The point (1,0)(1, 0)(1,0), with diag(8,−2)\mathrm{diag}(8, -2)diag(8,−2), is a saddle.

Near (1,0)(1, 0)(1,0) one step multiplies the offsets:

Every factor of 10 closer to the axis costs ln⁡10/ln⁡1.1≈24\ln 10 / \ln 1.1 \approx 24ln10/ln1.1≈24 extra steps. From φ=10°\varphi = 10°φ=10° (v0=0.28v_0 = 0.28v0​=0.28) the scene takes 48 steps. From φ=1°\varphi = 1°φ=1° (v0=0.028v_0 = 0.028v0​=0.028) it takes 72.

At φ=0°\varphi = 0°φ=0°, vvv stays 0. The path converges to the saddle, where the gradient is zero, and a test on ∥∇f∥\|\nabla f\|∥∇f∥ reports success at f=0.5f = 0.5f=0.5. A random start almost never lands on the axis, but nearby starts pay the toll.

The common mistake. A flat stretch in the loss curve is read as a local minimum, and the run is stopped. From φ=1°\varphi = 1°φ=1° the loss sits within 0.05 of the saddle value 0.5 for 22 steps, then drops to 0 on its own. A flat loss, or even a zero gradient, does not certify a minimum. A negative Hessian eigenvalue rules one out.

Saddles in high dimensions#

In DDD dimensions a critical point is a minimum only if all DDD Hessian eigenvalues are positive. For random Gaussian landscapes that chance decays exponentially with DDD, and critical points well above the lowest loss are almost all saddles. Dauphin et al. (2014) measured the same pattern in small networks. The scene's arithmetic carries over. A negative eigenvalue −λ-\lambda−λ escapes by a factor 1+ηλ1 + \eta\lambda1+ηλ per step, so a saddle costs time, not convergence. SGD noise also knocks the iterate off the stalling set.

Overparameterization#

A model is overparameterized when it can interpolate its training data, often with more parameters than examples (d≫nd \gg nd≫n). In practice its local minima are mostly near-global. That is a theorem only in special cases, such as deep linear nets (Kawaguchi, 2016), and an empirical finding elsewhere.

Initialization picks the basin#

The scene's start angle is an initialization. It picks the basin. In a network the weight scale also decides whether signal survives: too small and activations vanish, too large and they explode.

  • Xavier/Glorot (tanh, sigmoid): Wij∼U[−a,a]W_{ij} \sim \mathcal{U}[-a, a]Wij​∼U[−a,a] with a=6/(nin+nout)a = \sqrt{6/(n_{\text{in}} + n_{\text{out}})}a=6/(nin​+nout​)​, which keeps activation variance steady across layers.
  • He/Kaiming (ReLU): Wij∼N(0,2/nin)W_{ij} \sim \mathcal{N}(0, 2/n_{\text{in}})Wij​∼N(0,2/nin​). The factor 2 compensates for ReLU zeroing half the units.

Normalization as loss-surface shaping#

Batch Normalization (BNBatch Normalization) normalizes activations over a mini-batch. It was introduced against internal covariate shift (Ioffe & Szegedy, 2015), but its gain survives when that shift is re-injected (Santurkar et al., 2018). The benefit is a smoother loss, with a smaller LLL that allows larger steps. Layer Normalization (LNLayer Normalization) normalizes across the features of each example, at any batch size.

What transfers from convex theory#

Transfers as diagnosis: the step-size scale η≈1/L\eta \approx 1/Lη≈1/L, momentum (Week 7), adaptive methods (Week 8), gradient clipping (Week 9) and early stopping (Week 10).

Does not transfer: global optimality, predicted convergence rates and convex reformulation.

Browser lab: initialization on XOR#

Train a 2-layer MLP on XOR from He and from tiny initial weights. All-zero weights are a stationary point but not a minimum, so watch for a plateau at ln⁡2≈0.69\ln 2 \approx 0.69ln2≈0.69.

python · runs in browser
import numpy as np
import matplotlib.pyplot as plt

# Try np.random.seed(1): He init stalls at ln 2 / 2 = 0.35. One unit dies and no unit fires on two inputs.
# A 4-unit net is not overparameterized.
np.random.seed(0)

def relu(x): return np.maximum(0, x)
def drelu(x): return (x > 0).astype(float)
def sigmoid(x): return 1 / (1 + np.exp(-x))

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]]).T
y = np.array([[0, 1, 1, 0]])

def init_weights(d_in, d_hid, d_out, scale_fn):
    W1 = scale_fn(d_in, d_hid)
    b1 = np.zeros((d_hid, 1))
    W2 = scale_fn(d_hid, d_out)
    b2 = np.zeros((d_out, 1))
    return W1, b1, W2, b2

def forward(W1, b1, W2, b2, X):
    z1 = W1 @ X + b1; a1 = relu(z1)
    z2 = W2 @ a1 + b2; a2 = sigmoid(z2)
    return z1, a1, z2, a2

def compute_loss(a2, y):
    return -np.mean(y * np.log(a2 + 1e-12) + (1 - y) * np.log(1 - a2 + 1e-12))

def train(W1, b1, W2, b2, X, y, eta, K):
    losses = []
    for _ in range(K):
        z1, a1, z2, a2 = forward(W1, b1, W2, b2, X)
        losses.append(compute_loss(a2, y))
        dz2 = a2 - y
        dW2 = dz2 @ a1.T / 4; db2 = np.mean(dz2, axis=1, keepdims=True)
        dz1 = (W2.T @ dz2) * drelu(z1)
        dW1 = dz1 @ X.T / 4; db1 = np.mean(dz1, axis=1, keepdims=True)
        W1 -= eta * dW1; b1 -= eta * db1
        W2 -= eta * dW2; b2 -= eta * db2
    return losses

d_in, d_hid, d_out = 2, 4, 1
K, eta = 2000, 0.5

loss_he = train(*init_weights(d_in, d_hid, d_out,
    lambda i, o: np.random.randn(o, i) * np.sqrt(2.0 / i)), X, y, eta, K)

loss_small = train(*init_weights(d_in, d_hid, d_out,
    lambda i, o: np.random.randn(o, i) * 0.01), X, y, eta, K)

plt.figure(figsize=(8, 5))
plt.plot(loss_he, label="He init (√(2/n_in))", linewidth=1.5)
plt.plot(loss_small, label="Small randn × 0.01", linewidth=1.5)
plt.xscale("log"); plt.yscale("log"); plt.xlabel("Iteration"); plt.ylabel("Loss")
plt.title("XOR: He vs tiny init")
plt.legend(); plt.grid(True, alpha=0.3); plt.show()

print(f"Plateau: {sum(abs(l - np.log(2)) < 0.01 for l in loss_small)} steps within 0.01 of ln 2")
print(f"Final loss  He={loss_he[-1]:.4f}  small-init={loss_small[-1]:.4f}")
print("Notice: the tiny-weight run starts next to the all-zero stationary point. It sits on a plateau near ln 2 before it leaves.")

Key takeaways#

  • A critical point is a saddle when its Hessian has eigenvalues of both signs. Gradient descent stalls near one but leaves along the negative direction.
  • Near a saddle with curvature −λ-\lambda−λ, each factor of 10 closer to its stable set costs about ln⁡10/ln⁡(1+ηλ)\ln 10 / \ln(1 + \eta\lambda)ln10/ln(1+ηλ) extra steps. A plateau is not a minimum.
  • In high dimensions saddles outnumber minima. In overparameterized nets most minima are near-global in practice.
  • Initialization picks the basin, normalization smooths the surface, and convex theory transfers as diagnosis, not as guarantees.

  • Yann Dauphin et al., "Identifying and Attacking the Saddle Point Problem in High-Dimensional Non-Convex Optimization" (NeurIPS 2014). Why saddles dominate high-dimensional landscapes.
